============================================================
  EduFEM - Software Educativo de Elementos Finitos
  Version 1.0.0
============================================================

EduFEM es una aplicacion educativa de analisis por el Metodo de
Elementos Finitos (MEF) en 2D (tension plana / deformacion plana),
con elementos cuadrilateros Q4 y Q9.


------------------------------------------------------------
QUE PUEDE HACER EduFEM
------------------------------------------------------------
- Modela y resuelve problemas 2D de elasticidad lineal (tension
  plana y deformacion plana) con elementos Q4 y Q9.
- PRE-PROCESO: dibuja la malla sobre un lienzo, define materiales,
  cargas y restricciones; importa geometria desde DXF y modelos
  desde CSV/Excel.
- PROCESO: resuelve por el MEF y ofrece 8 modulos educativos
  interactivos que muestran paso a paso el mapeo isoparametrico,
  el Jacobiano, las matrices B y D, la rigidez con cuadratura de
  Gauss, las fuerzas equivalentes y el ensamblaje global.
- POST-PROCESO: contornos de tension y desplazamiento, malla
  deformada, vista 3D y sonda puntual con circulo de Mohr.
- Genera una Memoria de Calculo en PDF con el procedimiento
  completo, y exporta modelos y resultados a CSV/Excel.


------------------------------------------------------------
REQUISITOS
------------------------------------------------------------
- Sistema: Windows 10 u 11 de 64 bits.
- Memoria RAM: 4 GB recomendado (2 GB minimo).
- Disco: unos 300 MB libres (programa + extraccion temporal).
- No requiere conexion a internet ni tarjeta grafica dedicada.


------------------------------------------------------------
COMO ABRIR EL PROGRAMA
------------------------------------------------------------
Hace doble clic en el icono "EduFEM" del Escritorio, o buscalo
en el menu Inicio.

El PRIMER arranque es mas lento (puede tardar 10-40 segundos):
la primera vez el programa descomprime sus componentes. Espera
a que aparezca la ventana; no hagas doble clic varias veces.


------------------------------------------------------------
PRIMEROS PASOS
------------------------------------------------------------
- Menu "Ayuda" -> "Cargar Ejemplo": modelos de demostracion
  (cuadrado de validacion, viga de Timoshenko, membrana de Cook).
- Menu "Ayuda" -> "Manual" y "Atajos".
- Pulsa F5 (o abre la pestana POST-PROCESO) para resolver.
- Menu "Archivo" -> Guardar / Abrir: los modelos se guardan como
  archivos ".edufem" (podes retomarlos despues).


------------------------------------------------------------
MEMORIA DE CALCULO EN PDF  (requiere LaTeX / MiKTeX)
------------------------------------------------------------
La exportacion de la "Memoria de Calculo (PDF)" se genera con
LaTeX. Para que funcione, instala una distribucion TeX:

    MiKTeX  ->  https://miktex.org/download

Sin MiKTeX, TODO el resto del programa funciona normalmente; solo
esa exportacion no estara disponible. Si la intentas sin MiKTeX,
EduFEM muestra un aviso con un boton de descarga. Reinicia EduFEM
despues de instalar MiKTeX.


------------------------------------------------------------
MAS VELOCIDAD  (opcional -- libreria numba)
------------------------------------------------------------
EduFEM ejecuta los calculos en NumPy puro, lo cual es suficiente
para los modelos educativos. Si trabajas con mallas MUY grandes y
queres mas velocidad, podes usar la libreria "numba" (compilacion
JIT que acelera el calculo).

numba NO viene en la version instalada: para aprovecharla hay que
ejecutar el programa desde el codigo fuente:

  1) Descarga el repositorio del proyecto (ver SOPORTE, mas abajo).
  2) Crea un entorno virtual e instala las dependencias:

        python -m venv .venv
        .\.venv\Scripts\python.exe -m pip install -r requirements.txt
        .\.venv\Scripts\python.exe -m pip install numba

     (numba puede requerir una version de numpy compatible; si pip
     propone cambiar numpy, revisalo antes de aceptar.)

  3) Ejecuta el programa:

        .\.venv\Scripts\python.exe main.py

Para el uso normal de la tesis NO hace falta: la version instalada
alcanza de sobra.


------------------------------------------------------------
SOLUCION DE PROBLEMAS
------------------------------------------------------------
- El primer arranque tarda 10-40 s: es normal (se descomprimen los
  componentes la primera vez). Espera a que aparezca la ventana.
- Windows o el antivirus muestran un aviso de seguridad: es un
  falso positivo habitual en programas nuevos sin firma comercial;
  se permite la ejecucion (mas detalle en la instalacion).
- No se genera la Memoria PDF: falta MiKTeX (ver la seccion de
  arriba); instalalo y reinicia EduFEM.
- El programa no abre: verifica que el sistema sea Windows de 64
  bits y vuelve a instalar desde el instalador.
