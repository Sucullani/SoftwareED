============================================================
  EduFEM - Software Educativo de Elementos Finitos
  Guía de uso e instalación
  Versión 1.0.0
============================================================

EduFEM es una aplicación educativa de análisis por el Método de
Elementos Finitos (MEF) en 2D (tensión plana y deformación
plana), con elementos cuadriláteros Q4 y Q9.

Todo lo que el programa necesita viaja dentro del instalador:
no hay que instalar Python, ni MiKTeX, ni ninguna otra cosa, y
no hace falta conexión a internet ni permisos de administrador.


------------------------------------------------------------
1. QUÉ PUEDE HACER EduFEM
------------------------------------------------------------
- Modela y resuelve problemas 2D de elasticidad lineal (tensión
  plana y deformación plana) con elementos Q4 y Q9.
- PRE-PROCESO: dibuja la malla sobre un lienzo, define
  materiales, cargas y restricciones; importa geometría desde
  DXF y modelos desde CSV/Excel.
- PROCESO: resuelve por el MEF y ofrece 8 módulos educativos
  interactivos que muestran paso a paso el mapeo isoparamétrico,
  el Jacobiano, las matrices B y D, la rigidez con cuadratura de
  Gauss, las fuerzas equivalentes y el ensamblaje global.
- POST-PROCESO: contornos de tensión y desplazamiento, malla
  deformada, vista 3D y sonda puntual con círculo de Mohr.
- Genera una Memoria de Cálculo en PDF con el procedimiento
  completo, y exporta modelos y resultados a CSV/Excel.


------------------------------------------------------------
2. REQUISITOS
------------------------------------------------------------
- Sistema: Windows 10 u 11 de 64 bits.
- Memoria RAM: 4 GB recomendado (2 GB mínimo).
- Disco: unos 450 MB libres.
- No requiere internet, tarjeta gráfica dedicada, Python,
  MiKTeX ni permisos de administrador.


------------------------------------------------------------
3. INSTALACIÓN
------------------------------------------------------------
Doble clic en "EduFEM-Setup.exe" y seguir el asistente. La
instalación es para el usuario actual, así que Windows no pide
la contraseña de administrador.

El asistente permite elegir:
  - Crear un icono en el Escritorio (recomendado).
  - Asociar los archivos ".edufem" con EduFEM (recomendado):
    con eso, un proyecto se abre haciendo doble clic sobre él.

CARPETA DE INSTALACIÓN: si tu nombre de usuario de Windows
tiene tildes o espacios (por ejemplo C:\Users\José Pérez\...),
el asistente propone instalar en C:\ProgramData\EduFEM. Aceptá
esa carpeta: el generador de PDF que viene incluido no funciona
en rutas con esos caracteres.

La primera ejecución de "EduFEM-Setup.exe" puede mostrar el
aviso de seguridad de Windows; ver la sección 8.


------------------------------------------------------------
4. CÓMO ABRIR EL PROGRAMA
------------------------------------------------------------
Cualquiera de estas tres formas:
  - Doble clic en el icono "EduFEM" del Escritorio.
  - Menú Inicio -> carpeta "EduFEM" -> "EduFEM".
  - Tecla Windows + R, escribir  edufem  y Enter.

La ventana aparece en unos 3 segundos. La primera vez después
de instalar puede tardar unos segundos más, mientras Windows
revisa los archivos nuevos.


------------------------------------------------------------
5. LOS ARCHIVOS .edufem
------------------------------------------------------------
Los modelos se guardan con la extensión ".edufem" (menú Archivo
-> Guardar). La primera vez, el programa propone guardarlos en
la carpeta "Documentos\EduFEM"; después recuerda la última que
hayas usado. Si aceptaste la asociación durante la instalación,
esos archivos se muestran con el icono de EduFEM y se abren con
doble clic.

Si no la aceptaste y querés abrirlos así más adelante: clic
derecho sobre un ".edufem" -> Abrir con -> Elegir otra
aplicación -> EduFEM -> marcar "Usar siempre esta aplicación".


------------------------------------------------------------
6. PRIMEROS PASOS DENTRO DEL PROGRAMA
------------------------------------------------------------
- Menú "Ayuda" -> "Cargar Ejemplo": modelos de demostración
  (cuadrado de validación, viga de Timoshenko, membrana de
  Cook), en versiones Q4 y Q9.
- Menú "Ayuda" -> "Manual" y "Atajos" para más información.
- Pulsar F5 (o abrir la pestaña POST-PROCESO) para resolver.
- Menú "Archivo" -> Guardar / Abrir: los modelos se guardan como
  archivos ".edufem" y se pueden retomar después.


------------------------------------------------------------
7. MEMORIA DE CÁLCULO Y TEORÍA EN PDF (LaTeX incluido)
------------------------------------------------------------
La "Memoria de Cálculo (PDF)" y el documento "Teoría MEF" se
componen con LaTeX. EduFEM trae su propio motor LaTeX en la
carpeta "texlive", junto al programa: no hay que instalar
MiKTeX, no hace falta internet y no aparece ningún diálogo
pidiendo instalar paquetes.

Los dos documentos se abren con el visor de PDF de Windows
(Microsoft Edge, salvo que hayas elegido otro), en una ventana
aparte que puede quedar abierta mientras trabajás. La Teoría
MEF tarda unos segundos la primera vez, mientras se compila;
después se abre al instante.

Si esa carpeta faltara, EduFEM usa el pdflatex que encuentre
instalado en la PC; y si tampoco lo hay, muestra un aviso con un
botón de descarga. La solución más simple en ese caso es volver
a instalar EduFEM con el instalador completo.

Las fórmulas que se ven DENTRO del programa no usan LaTeX: se
dibujan con un motor propio y siempre están disponibles.


------------------------------------------------------------
8. SI APARECE "Windows protegió su PC" (SmartScreen)
------------------------------------------------------------
Puede aparecer al ejecutar "EduFEM-Setup.exe" por primera vez.
Es un aviso NORMAL de Windows ante programas nuevos sin firma
comercial. EduFEM NO es un virus: es una aplicación propia,
desarrollada como trabajo de tesis, y su código fuente completo
es público (ver la sección 11).

Para continuar:
  1) Clic en "Más información".
  2) Clic en el botón "Ejecutar de todas formas".

Una vez instalado, el programa se abre desde su icono sin
ningún aviso.

(Algunos antivirus también pueden marcar programas nuevos sin
firma: es un falso positivo habitual en aplicaciones generadas
con PyInstaller.)


------------------------------------------------------------
9. SOLUCIÓN DE PROBLEMAS
------------------------------------------------------------
- Aparece "Windows protegió su PC" o el antivirus lo marca:
  falso positivo habitual; ver la sección 8.
- No se genera la Memoria PDF: falta la carpeta "texlive" junto
  al programa (ver la sección 7). Reinstalá con el instalador
  completo.
- La Memoria PDF falla y el programa está instalado en una
  carpeta con tildes o espacios: reinstalá en
  C:\ProgramData\EduFEM (ver la sección 3).
- Se pide la Teoría MEF o la Memoria y no se abre nada:
  Windows no tiene un programa asociado a los archivos PDF. El
  aviso indica dónde quedó el archivo; se abre con cualquier
  visor de PDF.
- La ventana se ve cortada o los botones no entran: es un
  problema de escala de pantalla; probá bajar el zoom en
  Configuración de Windows -> Pantalla -> Escala.
- El programa no abre: verificá que el sistema sea Windows 10 u
  11 de 64 bits y volvé a instalar.
- Para reportar un problema, el instalador deja un registro en
  la carpeta temporal del usuario (archivos "Setup Log *.txt").


------------------------------------------------------------
10. DESINSTALAR
------------------------------------------------------------
Configuración de Windows -> Aplicaciones -> EduFEM ->
Desinstalar. También está el acceso "Desinstalar EduFEM" en la
carpeta EduFEM del menú Inicio.

La desinstalación borra el programa y el motor LaTeX incluido.
NO borra tus modelos ".edufem": esos quedan donde los hayas
guardado.

------------------------------------------------------------
12. NOTA: CARPETA PORTABLE
------------------------------------------------------------
Además del instalador, EduFEM puede entregarse como una carpeta
que no se instala. En ese caso hay que mantener juntos, en la
misma carpeta:

    EduFEM.exe                       el programa
    _internal\                       sus componentes (no tocar)
    texlive\                         el motor LaTeX (Memoria PDF)
    Iniciar EduFEM.bat               lanzador recomendado
    Crear acceso directo EduFEM.bat  crea el icono del Escritorio

Doble clic en "Iniciar EduFEM.bat" abre el programa evitando el
aviso de SmartScreen. En esta modalidad no hay asociación de
archivos ni entrada en el menú Inicio: para eso está el
instalador, que es la vía recomendada.
